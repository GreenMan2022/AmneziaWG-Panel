AmneziaWG Panel

Веб-панель управления VPN-сервером AmneziaWG (AWG) с аутентификацией, выдачей клиентских конфигов, QR-кодов, управлением сроками действия и детектором раздачи конфига.

Компоненты
Компонент	Описание
panel.py	Веб-панель на Python без зависимостей (порт 8000, админ-путь /1q2w3e4r)
panelctl	CLI-инструмент для управления клиентами
install.sh	Универсальный установщик для нового сервера
install_amneziawg.sh	Установщик AmneziaWG 2.0
connection_limit.sh	Детектор и блокировка раздачи конфига
Быстрый старт

На чистом VDS (Ubuntu 24.04 / Debian 12+):
bash

sudo apt update && sudo apt install -y git
git clone https://github.com/GreenMan2022/AmneziaWG-Panel/ panel
cd panel
sudo bash install.sh

Установка занимает несколько минут. По завершении скрипт выведет адрес панели, логин и пароль администратора.
Опции установки

install.sh поддерживает следующие параметры:
Опция	Описание	По умолчанию
--port=N	UDP-порт сервера AWG	443
--subnet=CIDR	Подсеть туннеля	10.9.9.1/24
--route=all|amnezia|custom:CIDR	Режим маршрутизации	all
--preset=default|mobile	Пресет обфускации	mobile
--no-cps / --cps	Вкл/выкл параметр I1 (CPS)	--no-cps
--skip-awg	Не трогать установленный AWG, переразвернуть только панель	—

Пример:
bash

sudo bash install.sh --port=51820 --subnet=10.0.0.1/24

Использование
Веб-панель

Адрес:
text

http://<IP-сервера>:8000/1q2w3e4r

Секретный путь можно изменить в panel.py (константа ADMIN_PATH).
CLI-команды

Все команды выполняются от root:
bash

panelctl status              # Статус панели и сервисов
panelctl add <имя>           # Создать клиента (срок 30 дней)
panelctl extend <имя> <дни>  # Продлить срок действия
panelctl list                # Список всех клиентов
panelctl blocked             # Заблокированные за раздачу
panelctl remove <имя>        # Удалить клиента
panelctl config              # Показать конфигурацию панели

Безопасность
Аутентификация

    Пароль администратора и соли генерируются случайно при установке

    Хранятся в /root/awg/panel.env (права 600)

    Панель использует переменные окружения:

        PANEL_ADMIN_USER

        PANEL_ADMIN_PASSWORD

        PANEL_HASH_SALT

        PANEL_CLIENT_AUTH_SALT

Важно: Без переменных окружения используются встроенные значения только для разработки. На боевом сервере они не должны применяться.
Защита данных

    Директория /root/awg/ содержит приватные ключи сервера и клиентов

    Эта папка исключена из git — никогда не публикуйте её

    Путь админ-панели /1q2w3e4r скрывает интерфейс (корень отдаёт 404)

    Рекомендуется дополнительно ограничить доступ через nginx или firewall
